# ShelfKit

Open-source firmware and tooling for e-ink price labels.

## Supported Hardware

- SES-imagotag Vusion BWR UU340 — only

## Repository Layout

- `firmware/` — device firmware for supported labels
- `access-point/` — access point / base station software
- `integrations/` — integrations with external systems
- `software/` — host-side tools and applications
- `documentation/` — project docs, hardware notes, and protocol references

## Status

Early development. Support is limited to the UU340.
